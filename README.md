# מצפן — RiskPlan

מחולל טיוטת סקר סיכונים ותוכנית ביקורת רב־שנתית בעברית, עבור גופים בישראל.

## הפעלה

פתחו את `dist/index.html` בדפדפן, או הריצו מתוך תיקיית המאגר:

```sh
python3 -m http.server 8080 --directory dist
```

לאחר מכן פתחו http://localhost:8080.

אין צורך בהתקנת תלויות או שרת יישום. גופן Heebo נטען מ־Google Fonts; בהיעדר חיבור נעשה שימוש בגופן מקומי חלופי.

## יכולות

- פרופיל ארגון והתייחסות למסגרת החוקית לפי סוג הגוף.
- סיכונים מוצעים, דירוג סבירות, השפעה ובקרות הניתן לעריכה.
- מפת סיכונים וחישוב סיכון שיורי משוער.
- תוכנית ל־3–5 שנים לפי תקציב שעות, רזרבה ודירוג סיכונים.
- הצגת פערי כיסוי וייצוא CSV או הדפסה ל־PDF.

## גבולות הגרסה

הנתונים מעובדים בדפדפן ואינם נשמרים אוטומטית. יש לייצא לפני סגירה או רענון. המנוע מבוסס כללים ואינו שירות AI. הדירוגים הראשוניים הם הצעות לתיקוף; הבקרות לא נבדקו בפועל. כל תחום משובץ פעם אחת, ללא תדירות אוטומטית או ביקורות חוזרות.

הטיוטה דורשת שיקול דעת, תיקוף ואישור של מבקר פנימי והגורם המאשר המתאים. הכלי אינו מאשר עמידה בחוק או בתקני IIA; התאמה משפטית והפניות דורשות אימות מול מקורות רשמיים עדכניים.

## מבנה

- `dist/index.html` — ממשק בעברית מימין לשמאל.
- `dist/style.css` — עיצוב רספונסיבי והדפסה.
- `dist/app.js` — דירוג, שיבוץ וייצוא.

העלאת המקור ל־GitHub אינה מפרסמת אתר חי. ניתן לארח את תוכן `dist/` בשירות אירוח סטטי.
